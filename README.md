# 📰 News Summarizer — Fine-tuned T5

An AI-powered news summarization app built with a fine-tuned T5 model
trained on the CNN/DailyMail dataset.

## 🚀 Live Demo
Paste any news article and get an instant AI-generated summary!

## 🧠 How It Works
1. T5-small model fine-tuned on CNN/DailyMail dataset (3000 samples)
2. User pastes a news article
3. Model generates a concise summary
4. Word count comparison shown (original vs summary)

## 🛠️ Tech Stack
- 🤗 Hugging Face Transformers (T5)
- 🔥 PyTorch
- 🎨 Streamlit
- 📊 CNN/DailyMail Dataset

## ⚙️ Setup & Run
1. Clone the repo
   git clone https://github.com/Arslank09/t5-news-summarizer.git

2. Install dependencies
   pip install -r requirements.txt

3. Run the app
   streamlit run app.py
